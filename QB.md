## 🔢 NUMERICALS THAT WILL DEFINITELY APPEAR

### Numerical 1 — RSA (100% chance)
```
Public key (E, N) = (7, 187)
→ Find p, q (factorize N=187 → p=11, q=17)
→ φ(N) = (p-1)(q-1) = 10×16 = 160
→ Find D: E×D ≡ 1 mod φ(N) → 7×D ≡ 1 mod 160 → D = 23
→ Encrypt M=10: C = 10^7 mod 187 = 10 (verify)
→ Decrypt C: M = C^23 mod 187 = 10
```

### Numerical 2 — Diffie-Hellman (very high chance)
```
p=11, g=7, x=3 (A's private), y=6 (B's private)
→ A's public key: α = g^x mod p = 7^3 mod 11 = 343 mod 11 = 2
→ B's public key: β = g^y mod p = 7^6 mod 11 = 117649 mod 11 = 4
→ Shared key (A computes): K = β^x mod p = 4^3 mod 11 = 64 mod 11 = 9
→ Shared key (B computes): K = α^y mod p = 2^6 mod 11 = 64 mod 11 = 9 ✓
```

### Numerical 3 — Playfair (appears every year, only key changes)
```
Key: CRYPTOGRAPHY → Remove duplicates → C-R-Y-P-T-O-G-A-H-B (fill rest)
Matrix:
C R Y P T
O G A H B
D E F I K
L M N Q S
U V W X Z
(I=J combined)

Message: NETWORK SECURITY
→ Prepare digraphs → NE TW OR KS EC UR IT YX
→ Apply rules (same row/col/rectangle)
```

### Numerical 4 — Euler's phi (5 marks, very easy)
```
φ(11)  = 10         (11 is prime → p-1)
φ(49)  = 42         (49 = 7² → 7²-7¹ = 49-7 = 42)
φ(240) = 64         (240 = 2⁴×3×5 → 240×(1-½)×(1-⅓)×(1-⅕) = 64)
```
