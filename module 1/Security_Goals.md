# Security Goals

In cryptography and system security, understanding the core security goals is fundamental. These goals highlight what every security system aims to protect and achieve:

## 1. Confidentiality
Ensures that information is not accessed by unauthorized persons. Only those who are authorized should have access to sensitive data.

- **Example:** Data encryption, password protection.

## 2. Integrity
Assures that data is accurate and unaltered during storage, transmission, and usage.

- **Example:** Using cryptographic hash functions (like SHA-256) to detect tampering.

## 3. Availability
Guarantees that information and resources are accessible to authorized users whenever needed.

- **Example:** Redundant network links, backup systems to prevent downtime.

## Additional Goals

- **Authentication:** Proving the identity of users/systems. Eg: Login via passwords or biometrics.
- **Non-repudiation:** Ensuring that an entity cannot deny its actions. Eg: Digital signatures.
- **Accountability:** Tracking who did what and when (logging, auditing).

A secure cryptographic system aims to provide these properties in all operations.
